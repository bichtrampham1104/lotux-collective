# DHIS2 & HL7 FHIR: a human-centred health data workflow exploration

**Status:** In progress  
**Location/context:** Vietnam-focused, exploratory portfolio project  
**Scope:** Learning and documentation; not an official system assessment.

## Why this matters
Health information is useful only when it can be collected, understood and exchanged responsibly. This project explores a selected health-data workflow through usability, data-quality and interoperability lenses.

## Research questions
1. What does the selected workflow ask a health worker or data user to do?
2. What usability and data-quality considerations appear in the workflow?
3. How might relevant HL7 FHIR resources represent or exchange a related piece of information?
4. What questions should be validated with practitioners before drawing conclusions?

## Planned methods
- Select one documented or publicly accessible DHIS2 workflow.
- Map the journey from data entry to reporting.
- Review usability, completeness, consistency, accessibility, privacy and practical usefulness.
- Select one relevant FHIR resource and create a small illustrative mapping.
- Record assumptions, limitations and questions for practitioner feedback.

## Deliverables
- Workflow diagram
- Usability and data-quality review checklist
- Small illustrative FHIR mapping
- Findings, limitations and follow-up questions

## Important limitations
DHIS2 and HL7 FHIR serve different roles and are not interchangeable. A public demo or documentation review does not establish how a live Vietnamese health facility uses a system. No patient data or unauthorised system access will be used. This is not clinical, regulatory or interoperability certification.

## Feedback wanted
Especially welcome: health informatics practitioners, DHIS2 implementers, FHIR developers, public-health researchers and health workers.
