# Explainable CXR AI

**Status:** Planned  
**Purpose:** Responsible-AI learning project; not a clinical tool.

## Question
How do model performance, visual explanations and practical computing constraints affect how people interpret a medical-imaging AI demonstration?

## Possible methods
- Choose a properly licensed, documented public dataset and a clearly defined task.
- Reproduce a baseline model and report appropriate evaluation metrics.
- Examine errors and class imbalance.
- Explore a visual explanation method such as Grad-CAM, while treating it as an imperfect aid rather than proof of model reasoning.
- Document hardware, image-size and inference constraints.

## Possible outputs
Dataset note, reproducible notebook, evaluation summary, explanation examples and limitations.

## Safety and limitations
No patient use, diagnosis or clinical validation. Dataset provenance, licensing, label quality and possible bias must be reviewed before analysis.
